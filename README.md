# ⚡ TaskFlow - Glassmorphism Task & Productivity Dashboard

A modern, responsive, single-page **Task & Productivity Dashboard** built with pure **Vanilla HTML5, CSS3, and JavaScript**. Features a sleek glassmorphism UI, daily progress & failure monitoring, sound alerts & alarm system, dynamic digital clock, gaming/sports categories, and real-time productivity analytics.

## ✨ Key Features

- 🌐 **Latest Web Browser Ready**: Optimized for fast load times and smooth animations across all modern browsers (Google Chrome, MS Edge, Firefox, Safari, Brave).
- 🕒 **Live Dynamic Clock & Smart Greeting**: Real-time digital clock with seconds precision and adaptive time-based greetings with customizable user name.
- 📊 **Daily Progress & Failure Monitor**: Automated day-by-day streak counter, productivity score calculations, and overdue task alerts.
- ⏰ **Scheduled Alarms & Sound Alerts**: Interactive audio chime notifications for task deadlines, alarms, and milestone achievements.
- 🎯 **Task Management & Priority System**:
  - Add and manage tasks with Priority levels (**High 🔴**, **Medium 🟡**, **Low 🟢**), Categories, and Due Dates.
  - Interactive checkboxes with completion sound feedback and strike-through animations.
  - Full CRUD support: Add, Edit, Toggle, and Delete tasks.
- 🎮 **Gaming & Activity Categories**:
  - **`Game (Online)` 🎮**: Esports, scrims, Discord sessions, multiplayer tournaments.
  - **`Game (Physical)` ⚽**: Football, basketball, gym workouts, outdoor sports, board games.
  - Work, Personal, Study, Health, and Finance categories.
- 🔍 **Real-time Search & Multi-filtering**: Filter by status (*All*, *Active*, *Completed*), category, priority, or keyword search.
- 🌙 **Dark & Light Mode**: Smooth theme switching with persistent memory in `localStorage`.
- 📱 **Responsive Glassmorphism UI**: Frosted glass effects, ambient glows, fluid micro-interactions, and mobile/tablet/desktop responsiveness.

## 🚀 Getting Started

No build tools, compilers, or Node.js required!

### Option 1: Open Directly in Web Browser
1. Clone or download this repository.
2. Double-click `index.html` to launch it immediately in your default browser.

### Option 2: Run via Local Web Server
If you prefer running through a local development server:

```bash
# Clone the repository
git clone https://github.com/anandmaurya22/Daily-Task-Managing-Software.git

# Navigate to project directory
cd Daily-Task-Managing-Software

# Start a local server (Python 3)
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.
